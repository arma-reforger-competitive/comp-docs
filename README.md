# ARC Competitive Docs

This repository contains all **documentation** for the  
**Arma Reforger Competitive** ecosystem.

It is intended as a reference for:

- Developers building or extending competitive modes  
- Server administrators running competitive layers  
- Players learning the rules and match flow

---

## 📂 Structure

``` text
/rulesets     → Competitive mode rules (player/tournament-facing)
/systems      → System design docs (roles, squads, layers, admin protocol)
/specs        → Developer technical specs (state machines, data models, events)
/terminology  → Definitions of terms and abbreviations
/philosophy   → Competitive design principles
/tournament   → Tournament operations, formats, and procedures
/server-setup → Server installation & configuration guides
```

---

## 📌 Notes

- Rulesets are versioned (e.g., `aas-v1.md`) for clarity and future updates.  
- This repo is **documentation only** — no game logic or assets are included.
